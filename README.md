## How I build

**Code gates the AI.** A model can propose. Deterministic checks decide.

**Measure first.** Evals, canary tests, and cost caps come with the feature, not after it.

**Ship it.** CI, typed code, and written specs on every project.

**Say what is simulated.** Every demo states its limits.
